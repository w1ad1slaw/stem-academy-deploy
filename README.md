# Скрипт автоматического развертывания среды STEM Академия

---

## Описание

Bash-скрипт `deploy.sh` предназначен для автоматической подготовки рабочей станции технопарка к работе с учебным комплектом STEM Академия Продвинутый.

Скрипт выполняет полный цикл развертывания: от обновления системы до создания структуры проектов и настройки прав доступа к оборудованию.

---

## Назначение

- Автоматизация рутинных операций администратора при подготовке новой рабочей станции
- Устранение человеческого фактора при настройке прав доступа к последовательным портам
- Стандартизация среды разработки для всех рабочих мест технопарка
- Соответствие требованиям ПК 4.3 индивидуального задания практики

---

## Требования

| Компонент | Минимальные требования |
|-----------|------------------------|
| ОС | Ubuntu 22.04+ / Xubuntu 22.04+ / Debian 11+ |
| Права | root / sudo |
| Интернет | Требуется для обновления пакетов |

## Запуск

### 1. Клонирование репозитория

    git clone https://github.com/w1ad1slaw/stem-academy-deploy
    cd stem-academy-deploy

### 2. Предоставление прав на выполнение

    chmod +x deploy_stem.sh

### 3. Запуск от имени суперпользователя

    sudo ./deploy_stem.sh

Важно: скрипт требует прав суперпользователя. При запуске без sudo будет выведено сообщение об ошибке и скрипт завершит работу.

---

## Что делает скрипт

Скрипт выполняет 5 этапов развертывания:

### Этап 1: Обновление системы

- Обновление списков пакетов (`apt update`)
- Установка доступных обновлений (`apt upgrade`)

### Этап 2: Установка программного обеспечения

Устанавливаются следующие пакеты:

- `python3`, `python3-pip` — интерпретатор Python и менеджер пакетов
- `git` — система контроля версий
- `python3-serial` — библиотека для работы с последовательными портами (UART/USB)
- `minicom` — терминальная программа для отладки UART-соединений
- `arduino-cli` — инструмент командной строки для работы с Arduino

### Этап 3: Настройка прав доступа

- Текущий пользователь добавляется в группу `dialout`
- Это позволяет работать с устройствами `/dev/ttyUSB0` и `/dev/ttyACM0` без использования `sudo`

### Этап 4: Создание структуры проектов

В домашнем каталоге пользователя создаётся директория `STEM_Academy_Projects` с подпапками:

- `Arduino_Sketches/` — скетчи для Arduino
- `Python_Scripts/` — скрипты на Python
- `Documentation/` — документация проектов

### Этап 5: Проверка установленных компонентов

Выводятся версии установленного ПО для верификации успешной установки.

## Возможные проблемы

### Скрипт должен быть запущен от имени суперпользователя

Решение: запустите скрипт с префиксом `sudo`:

    sudo ./deploy_stem.sh

### Пользователь не добавлен в группу dialout

Решение: после выполнения скрипта необходимо выйти из системы и войти заново (или перезагрузить ПК), чтобы изменения в группах вступили в силу.

### Ошибка при установке пакетов

Решение: проверьте подключение к интернету и актуальность списков пакетов:

    sudo apt update
